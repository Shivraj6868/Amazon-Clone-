# 🛒 Amazon Clone Web Application


A frontend clone of Amazon's website homepage built using **HTML5 and CSS3**.

This project was created to practice real-world frontend development concepts like webpage structure, layouts, CSS styling, Flexbox, positioning, hover effects, and Git/GitHub workflow.
